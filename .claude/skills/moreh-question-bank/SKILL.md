# Question bank
1. Read content/campus/SPEC.md and relevant existing question formats before editing.
2. Use only documented facts with traceable source IDs.
3. Draft clear Hebrew questions with four options and one unambiguously correct answer.
4. Make distractors plausible, similar in length and grammatical form; avoid giveaway wording.
5. Check chronology, geographical names, transliteration, and consistency with source.
6. Detect duplicates and near-duplicates against existing topic banks.
7. Place unsupported or disputed questions on hold, never in the active bank.
8. Run existing build and validation scripts on a branch; document the results.
